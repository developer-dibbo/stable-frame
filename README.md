🖼️ Stable Frame

A modern and minimal **photo framing web application** that allows users to upload artwork, apply beautiful frames, adjust image positioning, and export final framed images.

Designed with a clean and elegant UI using the **Stable Frame** brand color palette.

✨ Features

📤 Artwork Upload
- Upload your photo or artwork easily
- Supports image upload directly into canvas
- 
🖼️ Frame Selection
- Choose different frame styles
- Apply frames instantly to uploaded artwork

⚙️ Image Adjustments
Users can customize artwork placement with:

- Zoom control
- Opacity control

🎨 Canvas Interaction

Smooth and interactive canvas experience:

- Scroll over canvas to zoom in/out
- Drag to reposition photo
- Double-click to reset image position

📥 Export Options

Download framed artwork in:

- PNG
- JPEG
- WEBP

🎯 Website Layout

Simple one-page design:

### Header
- Centered Stable Frame logo

### Body
Two-column layout:

**Sidebar Controls**
- Upload Artwork
